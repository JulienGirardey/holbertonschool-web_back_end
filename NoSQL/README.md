# NoSQL

Ce dossier contient des exercices d'introduction à la base de données NoSQL, principalement MongoDB.

## Contenu

- Création et utilisation de bases de données
- Manipulation de documents et collections
- Requêtes, mises à jour et suppressions
- Scripts Python pour interagir avec MongoDB

## Utilisation

Certains scripts sont à exécuter dans le shell MongoDB, d'autres en Python :
```bash
python3 10-main.py
```
