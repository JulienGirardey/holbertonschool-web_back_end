# Holberton School - Web Back End

Ce dépôt regroupe des projets et exercices pour apprendre le développement back-end avec différentes technologies : JavaScript (ES6), Node.js, NoSQL, Python asynchrone, pagination, et plus.

## Structure du projet

Chaque dossier correspond à un module ou une thématique spécifique :

- **ES6_basic** : Découverte des bases d'ES6 (const, let, arrow functions, etc.)
- **ES6_classes** : Programmation orientée objet avec ES6 (classes, héritage, etc.)
- **ES6_data_manipulation** : Manipulation avancée de données en JavaScript
- **ES6_data_manipulation_C27** : Exercices complémentaires de manipulation de données
- **ES6_promise** : Utilisation des Promises en JavaScript
- **Node_JS_basic** : Premiers pas avec Node.js (lecture de fichiers, HTTP, Express...)
- **NoSQL** : Introduction à la base de données NoSQL (MongoDB)
- **pagination** : Gestion de la pagination côté serveur
- **python_async_comprehension** : Exercices sur les compréhensions asynchrones en Python
- **python_async_function** : Fonctions asynchrones en Python
- **python_variable_annotations** : Annotations de variables en Python

## Prérequis

- Node.js >= 14.x (pour les projets JS)
- Python >= 3.7 (pour les projets Python)
- MongoDB (pour NoSQL)

## Installation & Utilisation

1. Cloner le dépôt :
	```bash
	git clone <url-du-repo>
	cd holbertonschool-web_back_end
	```
2. Aller dans le dossier du module souhaité
3. Suivre les instructions du README du module
