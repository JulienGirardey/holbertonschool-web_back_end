# Node.js Basic

Ce dossier contient des exercices pour découvrir les bases de Node.js.

## Contenu

- Lecture de fichiers synchrones et asynchrones
- Création de serveurs HTTP simples
- Utilisation d'Express.js
- Manipulation de flux d'entrée/sortie

## Fichiers

Chaque fichier `*-main.js` permet de tester les fonctions associées.

## Utilisation

Exécuter un fichier de test avec Node.js :
```bash
node 0-main.js
```
