# ES6 Promise

Ce dossier regroupe des exercices sur l'utilisation des Promises en JavaScript (ES6).

## Contenu

- Création et gestion de Promises
- Utilisation de `then`, `catch`, `finally`
- Exécution parallèle avec `Promise.all`
- Gestion d'erreurs asynchrones

## Fichiers

Chaque fichier `*-main.js` permet de tester les fonctions associées.

## Utilisation

Exécuter un fichier de test avec Node.js :
```bash
node 0-main.js
```
