# Python Async Function

Ce dossier contient des exercices sur les fonctions asynchrones en Python.

## Contenu

- Définition et utilisation de fonctions `async` et `await`
- Gestion des tâches asynchrones
- Exécution concurrente avec asyncio

## Utilisation

Exécuter les scripts Python :
```bash
python3 <script>.py
```
