# Python Async Comprehension

Ce dossier contient des exercices sur les compréhensions asynchrones en Python.

## Contenu

- Utilisation des compréhensions asynchrones (`async for`, `async with`)
- Manipulation de coroutines et d'itérateurs asynchrones

## Utilisation

Exécuter les scripts Python :
```bash
python3 <script>.py
```
