# ES6 Classes

Ce dossier regroupe des exercices sur la programmation orientée objet en JavaScript avec ES6.

## Contenu

- Définition et utilisation de classes
- Héritage et polymorphisme
- Encapsulation et méthodes
- Exercices sur la gestion de cours, de devises, de bâtiments, d'aéroports, etc.

## Fichiers

Chaque fichier `*-main.js` permet de tester les classes et fonctions associées.

## Utilisation

Exécuter un fichier de test avec Node.js :
```bash
node 0-main.js
```
