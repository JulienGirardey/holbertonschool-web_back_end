# ES6 Data Manipulation

Ce dossier contient des exercices sur la manipulation de données en JavaScript avec ES6.

## Contenu

- Manipulation de listes et d'objets
- Utilisation de méthodes avancées (`map`, `filter`, `reduce`, etc.)
- Gestion des types et des ensembles

## Fichiers

Chaque fichier `*-main.js` permet de tester les fonctions associées.

## Utilisation

Exécuter un fichier de test avec Node.js :
```bash
node 0-main.js
```
