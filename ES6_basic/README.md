# ES6 Basic

Ce dossier contient des exercices pour découvrir les fonctionnalités de base d'ES6 (ECMAScript 2015) en JavaScript.

## Contenu

- Déclaration de constantes et variables (`const`, `let`)
- Fonctions fléchées
- Paramètres par défaut
- Opérateur de rest et spread
- Interpolation de chaînes
- Manipulation d'objets et de tableaux
- Boucles et itérations

## Fichiers

Chaque fichier correspond à un exercice spécifique. Les fichiers `*-main.js` servent à tester les fonctions implémentées.

## Utilisation

Exécuter un fichier de test avec Node.js :
```bash
node 0-main.js
```
