# Pagination

Ce dossier contient des exercices sur la gestion de la pagination côté serveur.

## Contenu

- Implémentation de la pagination sur des ensembles de données volumineux
- Gestion des pages, limites, et offsets
- Exemples en Python

## Utilisation

Exécuter les scripts Python pour tester la pagination :
```bash
python3 <script>.py
```
